# System kontroli manipulatora

Projekt inżynierski stanowiska uniwersalnego trzyosiowego manipulatora z opartym na mikrokontrolerze systemem kontroli oraz z podglądem wideo w czasie rzeczywistym.

## Struktura projektu

- `frontend/` — React, TypeScript, Vite i Tailwind CSS
- `backend/` — Backend w Go, planowany do implementacji na NVIDIA Jetson

## Aktualny status

Początkowy rozwój panelu sterowania od strony frontendu.



# Manipulator Control System

Engineering project of a universal three-axis manipulator workstation with a
microcontroller-based control system and live video preview.

## Project structure

- `frontend/` — React, TypeScript, Vite and Tailwind CSS
- `backend/` — Go backend planned for deployment on NVIDIA Jetson

## Current status

Initial development of the frontend control dashboard.
